# BOSS 直聘助手 · 使用说明

一个帮你在 BOSS 直聘上**自动筛选岗位**、**自动点「立即沟通」**的小工具。
登录一次，之后每次双击几个 .bat 就行。

---

## 一、它能做什么

- 按你设的方向（算法 / 大模型 / AI 应用 / 后端 / 测试 / 数据分析）在**深圳**搜岗位
- 自动过滤：不想要的词（外包、驻场、销售…）、薪资低于 15K 的、不在深圳的
- 对符合的岗位自动点「立即沟通」，BOSS 会用它自己的**打招呼语**发出去
- 把抓到的岗位和已沟通名单存成表格，随时能看

它**不会**做：替你和 HR 聊天、帮你投简历、自动回复消息。

---

## 二、第一次用（三步）

### 1. 登录（只需一次，掉线了再跑）

双击 **`1-Login.bat`**

会弹出一个 Chrome 窗口 → 用手机 BOSS App 扫码登录。
登录成功后窗口不会自己关，**你手动关掉就行**（关早了登录态存不下来）。

### 2. 筛选岗位

双击 **`2-Scan.bat`**

它会按 8 个关键词各搜一遍，屏幕上的 Chrome 会自己翻页滚动，别去动它。
跑完会显示「共抓到 N 个，符合 M 个」，大约 3~8 分钟。

### 3. 自动打招呼

先看名单：双击 **`4-Report.bat`** → 打开 `data\report.md`（同名的 `.csv` 可以用 Excel 直接开）

觉得名单没问题，就双击 **`3-Greet.bat`**

- 每天最多发 **25 个**（BOSS 自己也有限制，发多了会被限流）
- 每个之间随机等 60~120 秒，模拟真人节奏
- 想先看效果不真发：双击 **`5-DryRun.bat`**（只走到聊天框，不发送）

> 每天 25 次是**跨天累计**的，第二天 0 点自动重置。

---

## 三、招呼语在哪里改（重要）

本工具点的是「立即沟通」按钮，**发出去的那段话是 BOSS 自己设置里的「打招呼语」**，不是脚本里写的。

所以要先在 BOSS 里换成你想要的：

- 手机 App：**我的 → 设置 → 打招呼语**
- 网页版：**右上角头像 → 设置 → 打招呼语**

推荐文案：

> BOSS您好，我叫陈卓，毕业于湖北师范大学文理学院，数据科学与大数据技术专业，全日制本科学历，现居住地深圳。看到您的岗位觉得我非常匹配，可以给您发一份简历看看吗？

设好之后，以后每次点「立即沟通」都会自动带上这段话。

## 四、文件都是干什么的

| 文件 | 作用 |
| --- | --- |
| `1-Login.bat` | 打开 Chrome 让你扫码登录，登录态存在 `boss\profile\` |
| `2-Scan.bat` | 搜索 + 筛选，结果写进 `data\jobs.json` |
| `3-Greet.bat` | 对筛出来的岗位逐个点「立即沟通」 |
| `4-Report.bat` | 生成 `data\report.md` / `report.csv` 名单 |
| `5-DryRun.bat` | 演练模式：只打开聊天框打字，**不发送** |
| `6-Debug.bat` | 抓现场：存一张 `data\debug.png` 和页面源码，改版时用 |
| `config.json` | 城市、关键词、薪资下限、每日上限、间隔时间 |
| `data\contacted.json` | 已经沟通过的岗位（不会重复发） |
| `data\run-*.log` | 每天一份运行日志 |

## 五、常见问题

**Q：Chrome 窗口一闪就关了，或者页面变成一片空白？**
A：两种可能。① 已经有 Chrome 占着登录目录 —— 把所有 Chrome 窗口关掉再跑；② BOSS 的风控把它甩回空白页 —— 脚本会自动重试 3 次，还不行就跳过。连续多个都这样，说明频率太高了，把 `config.json` 里 `minGapSec` / `maxGapSec` 调大（比如 180 / 300）。

**Q：日志里写「岗位已下架 / 停止招聘」？**
A：这个岗位已经关了，正常跳过，不影响。

**Q：提示「今天的沟通次数已达上限」？**
A：25 次用完了，明天 0 点自动恢复。

**Q：提示「没找到立即沟通按钮」？**
A：多半是岗位页没加载出来（风控），或者需要重新登录。先跑一次 `1-Login.bat`。

**Q：能改城市 / 加关键词吗？**
A：可以，改 `config.json` 里的 `city`（城市码，深圳是 `101280600`）、`cityName`、`keywords` 数组。

**Q：会不会被封号？**
A：有这个风险。BOSS 的用户协议不允许自动化操作，工具已经尽量做得像真人（随机间隔、逐字输入、每天 25 个上限），但**不建议无人值守长时间跑**，也不要用新注册的小号。

## 六、它大概是怎么工作的

1. 用 Chrome 的调试端口打开浏览器（所以你看到的窗口是正常 Chrome，登录态就是你自己的）
2. 搜索时**直接读网页自己发的数据接口**（`/wapi/zpgeek/search/joblist.json`），而不是解析页面上的文字 —— 因为 BOSS 把薪资数字做了字体混淆，页面上扒出来的数字是坏的
3. 打开岗位详情页，按文字找「立即沟通 / 继续沟通」按钮并点击
4. 每步都有失败留证：`data\greet-fail.png`、`data\debug.png`
