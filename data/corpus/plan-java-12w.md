# 学习计划：从应届到「一年经验岗位」可投

> 制定依据：你 BOSS 助手里筛的 8 个方向（算法工程师 / 大模型 / AI 应用 / Java 开发 / Python / 后端开发 / 测试开发 / 数据分析）、你的简历（Java + Spring Boot 两个项目、数据科学专业、2026 届）、目标「一年左右经验」的岗位。
>
> 时间假设：**每天 4–6 小时、每周 6 天**，12 周为一个大周期（约 360 小时），后面接 8–12 周进阶与投递。
> 如果每天只有 2–3 小时，把所有周数 × 1.8。

---

## 一、先想清楚：你在跟谁抢「一年经验」的岗位

一年经验的岗位，招聘方真正要的是三件事：

1. **能独立接一个模块**，不用人盯着写（接口设计、表设计、联调）
2. **会用中间件**（Redis、消息队列），知道什么场景该用
3. **出过线上问题、会查**（看日志、看监控、定位慢 SQL）

应届生想投这类岗位，只有一种打法：**用「做过的东西」去抵「干过的年头」**。
所以这份计划的重心不是"学完多少知识点"，而是**产出 2–3 个能讲 20 分钟、有数字、有坑有解法的项目**。

## 二、8 个方向怎么取舍（重要）

| 方向 | 招聘现实 | 你的匹配度 | 建议 |
|---|---|---|---|
| **Java 开发 / 后端开发** | 岗位最多，深圳需求大 | ★★★★☆ 有基础、有项目 | **主攻**（占 60% 精力） |
| **Python / AI 应用** | 增长快，门槛中等 | ★★★☆☆ Python 会一点 | **兼投**（占 25%） |
| **数据分析** | 岗位偏少，常要业务经验 | ★★★★☆ 专业对口 | **兼投**（合并进 AI 应用） |
| **测试开发** | 门槛低于开发，起薪略低但好转 | ★★★☆☆ | **保底**（只花 3 天准备） |
| **算法工程师** | 基本卡硕士 + 论文/竞赛 | ★☆☆☆☆ | **放弃**（除非读研） |
| **大模型（算法向）** | 同上，且要训练/微调经验 | ★☆☆☆☆ | **放弃**；改投"大模型应用开发" |

**一句话结论：主攻 Java 后端，用"数据 + AI 应用"做差异化标签，测试开发兜底。**

## 三、能力差距诊断（对照一年经验岗位的真实要求）

| 能力 | 现在 | 一年经验岗位要求 | 差距 |

——差距集中在**"工程能力"**，不是"再多学一个框架"。所以下面每一周都配一个**动手产出**，不做纯看视频。

## 四、12 周主计划（每周 6 天 × 4–6 小时）

### 第 0 周（第 1 周）：地基与门面（约 30 小时）

**学什么**
- Git 与 GitHub：分支模型、PR、`.gitignore`、README 写法（4h）
- Linux 常用命令：`top / df -h / free / netstat / ss / lsof / grep / awk / tail -f / journalctl`（6h）
- 把两个老项目传 GitHub：写 README（怎么跑、接口列表、截图）（8h）
- 学习环境：JDK 17、Maven、IDEA 插件、Postman、DBeaver、Docker Desktop（4h）
- 简历升级：把 `【】` 里的数字填掉（4h）

**怎么学**：Git 只看 [Pro Git 前 3 章] + 动手建仓库；Linux 命令用"每天 5 条 + 当天用一遍"的方式记，不要背表。

**产出**：GitHub 上有 2 个能跑的项目仓库 + 一份 README 规范；简历 1 页定稿。

---

### 第 1–2 周：Java 深水区（约 60 小时）

**学什么**
1. **集合源码**（12h）：`ArrayList` 扩容、`HashMap` 数组+链表+红黑树、`ConcurrentHashMap` 分段/CAS、`LinkedHashMap`
2. **并发编程**（20h）：线程生命周期、`synchronized` 与锁升级、`volatile`、`CAS`、`AQS`、`ReentrantLock`、线程池七参数与拒绝策略、`CompletableFuture`、`ThreadLocal` 与内存泄漏
3. **JVM**（14h）：内存结构、对象创建与逃逸分析、GC 算法与收集器（G1）、常见 OOM 排查、`jps/jstack/jmap/jstat`
4. **Java 8+ 特性**（6h）：Stream、Optional、Lambda、新日期 API
5. **代码规范**（4h）：阿里 Java 开发手册（挑"集合/并发/异常"三章）
6. **算法题启动**（4h）：每天 1 题 LeetCode（数组、字符串、哈希）

**怎么学**：每个知识点按「**先跑 demo → 再看源码关键 20 行 → 写成一篇 300 字笔记**」三步走。**不要通读源码**，只看面试常问的那几段。

**产出**：一份《Java 并发与 JVM 笔记》（20 条以上，每条有自己的 demo 代码）；LeetCode 累计 20 题。

---

### 第 3–4 周：MySQL + Spring 体系（约 60 小时）

**学什么**
1. **MySQL**（24h）
   - 索引：B+ 树结构、聚簇/二级索引、回表、最左前缀、覆盖索引、索引失效 8 种场景
   - 事务：ACID、四种隔离级别、MVCC、间隙锁
   - 优化：`EXPLAIN` 各字段含义、慢查询日志、`limit` 深分页优化、count 优化
   - 设计：三范式与反范式、字段类型选择、分库分表的基本思路（不深入）
2. **Spring**（24h）
   - IoC：Bean 生命周期、循环依赖三级缓存
   - AOP：动态代理、事务失效的 6 种场景
   - Spring Boot：自动配置原理、`starter` 机制、配置文件优先级
   - 实战：全局异常处理、统一返回、参数校验、拦截器、日志切面
3. **MyBatis / MyBatis-Plus**（6h）：`#{}` vs `${}`、一级二级缓存、插件机制
4. **算法题**（6h）：每天 1 题（链表、栈、二分）

**怎么学**：MySQL 用 `explain` 在真实数据上验证每一条结论（造 10 万行数据）；Spring 用手写一个"迷你 Spring"（Bean 容器 + 简单 AOP）来理解，比看视频有效 10 倍。

**产出**：**项目 A 升级版**——把宿舍电量系统改成：统一返回体 + 全局异常 + 参数校验 + 分页 + 索引优化（贴 EXPLAIN 前后对比）+ Swagger 文档。README 里写清"优化前 800ms → 优化后 90ms"。

---

### 第 5–6 周：Redis + 消息队列（约 60 小时）

**学什么**
1. **Redis**（26h）
   - 五种基本类型 + 使用场景（String 计数、Hash 存对象、ZSet 排行榜/延时队列、List 队列、Set 去重）
   - 持久化 RDB/AOF、过期策略、内存淘汰
   - **缓存三大问题**：穿透（布隆过滤器/空值缓存）、击穿（互斥锁/逻辑过期）、雪崩（随机过期/多级缓存）
   - 分布式锁：`SETNX + 过期`、锁续期（Redisson 看门狗）、可重入
   - 缓存一致性：先删缓存还是先更库、延迟双删
2. **消息队列**（22h，选 **RabbitMQ**，教程多、概念清晰）
   - 交换机四种类型、死信队列、延迟队列
   - 可靠投递（确认机制）、幂等消费、顺序消息
   - 场景：异步解耦、削峰、分布式事务（本地消息表）
3. **算法题**（12h）：每天 1 题（二叉树、DFS/BFS）

**怎么学**：每个知识点都**必须落到项目里**——不会用等于没学。Redis 用 Docker 起一个，MQ 用 Docker 起一个（顺便练 Docker）。

**产出**：项目 A 加两个功能：① 热点宿舍数据 Redis 缓存 + 缓存击穿保护；② 充值成功后发 MQ 异步写流水/发通知。

---

### 第 7–8 周：工程化 + 高并发项目 B（约 60 小时）

**学什么**
1. **工程化**（24h）
   - Maven 多模块、依赖管理、`profile` 分环境
   - 单元测试：JUnit5 + Mockito，覆盖率意识
   - 日志：Logback 配置、traceId 串联
   - Docker：`Dockerfile` 写 Java 镜像、`docker-compose` 起 MySQL+Redis+MQ
   - Nginx 反向代理 + 简单限流
   - 监控入门：Spring Boot Actuator + Prometheus + Grafana（各 2 小时够了）
2. **项目 B：秒杀/抢购系统**（30h）
   - 要点：库存预热到 Redis、Lua 脚本扣减、MQ 异步下单、令牌桶限流、接口幂等、超卖防护、压测（JMeter 或 wrk）
   - 这一套是**面试最吃的项目**，能讲清楚就是"有一年经验"的水平
3. **算法题**（6h）：每天 1 题（动态规划入门）

**产出**：项目 B 上线（本机 Docker 跑），README 写明：QPS 从多少提升到多少、怎么防超卖、压测报告截图。

### 第 9–10 周：数据 + AI 应用（做差异化）（约 60 小时）

**学什么**
1. **数据分析**（16h）：pandas 数据清洗、分组聚合、Matplotlib/Plotly 出图、SQL 窗口函数、漏斗与留存分析
2. **大模型应用开发**（30h）
   - Prompt 工程：结构化输出、Few-shot、思维链
   - **RAG**：文档切分 → 向量化（bge/m3e）→ 向量库（pgvector 或 Milvus）→ 检索 → 重排 → 生成
   - Function Calling / Tool 调用、流式输出
   - 评测：准确率、召回率、幻觉控制
   - 用 **LangChain4j**（Java）做一版，正好串起你的两个方向
3. **算法题**（14h）：每天 1 题（Hot 100 剩余）

**产出**：**项目 C**（二选一）
- C1《深圳技术岗招聘数据分析》：爬 3000 条 JD → 清洗 → 词频/薪资分布 → 看板（这个项目还能反哺你的求职）
- C2《企业知识库问答服务》：Spring Boot + LangChain4j + pgvector，支持上传文档问答，带评测脚本

> 这两个项目是**你和纯 Java 候选人的区别**，面试时说"我用 Java 做过 RAG 服务"比"我了解 LangChain"强 10 倍。

### 第 11–12 周：面试冲刺（约 60 小时）

**学什么**
1. **八股系统过一遍**（20h）：Java 基础/集合/并发/JVM、MySQL、Redis、MQ、网络（TCP 三次握手、HTTP/HTTPS）、操作系统（进程线程、IO 模型）
2. **项目讲述**（12h）：每个项目准备 3 个版本——30 秒版（电梯）、3 分钟版（面试）、10 分钟版（深挖）；每个项目准备 3 个"最难的点 + 怎么解决"
3. **算法题**（16h）：Hot 100 二刷，重点：哈希、双指针、二叉树、DP
4. **模拟面试**（8h）：找同学/用 AI 扮演面试官，录音回听
5. **投递运营**（4h）：BOSS 助手每天 25 条、按"新发布 + 50 人以下小厂 + 一年经验"优先

**产出**：一份《面试题库 + 我的答案》文档（至少 60 题）；三个项目的 STAR 讲稿。

## 七、怎么学才有效（比学什么更重要）

1. **输出倒逼输入**：每个模块结束必须产出一篇笔记或一段代码，否则不算学完。
2. **只学"能讲出来"的部分**：判断标准是——合上资料，能不能给一个不懂的人讲 3 分钟。讲不出就是没学会。
3. **源码只看 20 行**：`HashMap.put` 的核心分支、`ThreadPoolExecutor.execute` 的三步、`AOP` 代理创建。别陷进去。
4. **项目要有"取舍"**：面试官最爱问"为什么用 Redis 不用本地缓存""为什么选 RabbitMQ 不选 Kafka"，答不出说明你只是抄教程。
5. **善用 AI，但别外包思考**：可以让 AI 解释源码、生成测试数据、review 代码；但每个技术决策要自己说得出理由。
6. **每周复盘 30 分钟**：这周学了什么、能讲几个点、下周补什么。

## 九、几个坑，提前说

1. **别囤课**：买了不看的课等于零。一个知识点最多看 1 个视频 + 1 篇文档，剩下时间写代码。
2. **别追求"学完再投"**：第 6 周就可以开始投，面试是最好的学习。
3. **别做第 4 个项目**：3 个讲透 > 6 个半成品。
4. **别信"一个月速成"**：一年经验的岗位，面试官 10 分钟就能问出你练了多久。
5. **投递别只盯大厂**：深圳 50–500 人的中小公司，一年经验岗位最多、流程最快、最愿意给应届机会。
